# Students-Performance-Prediction
(S5 BCA Minor Project - Students Performance Prediction)

This project focuses on predicting students’ final academic performance using demographic, behavioural, and academic attributes. It utilizes the Student Performance Dataset from Kaggle, which includes information on students’ personal backgrounds, family environments, study habits, attendance, and prior academic results. The workflow includes data preprocessing, exploratory data analysis, and the development of a Linear Regression model to predict final grades. Model performance is evaluated using MAE, MSE, and R² metrics, along with visual analysis.
The goal of this project is to provide an interpretable, data-driven approach to help educators identify students who may need additional academic support and improve overall learning outcomes.

Dataset Credit :
https://www.kaggle.com/datasets/dillonmyrick/high-school-student-performance-and-demographics
